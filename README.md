# Python Engineering Notes

A structured repository containing personal notes, guides, and reference materials focused on Python development, its ecosystem, and related technologies.

## 📁 Repository Structure

- **`core_python/`** 
  Core language mechanics, conventions, and comparisons.
  - `python_vs_ts.md`: Python vs TypeScript/JavaScript comparison.
  - `python.md`: General Python notes.
  - `operators.md`: Python operators and behaviors.
  - `intern_and_pool.md`: Object interning and memory efficiency.
  - `naming_conventions.md`: PEP 8 and standard naming conventions.

- **`ecosystem/`**
  Tools, frameworks, and infrastructure surrounding Python.
  - `fastapi.md`: Building APIs with FastAPI (REST, routing, async, middleware).
  - `database.md`: Database integrations (PostgreSQL, SQLite, SQLModel, ORMs).
  - `kubernetes.md`: Container orchestration and cloud-native deployments.
  - `rendering_types_and_auth.md`: Notes on CSR, SSR, SSG, and FastAPI backend authentication.

- **`ai/`**
  Artificial Intelligence and specialized topics.
  - `ai_stuffs.md`: General AI notes, evolution, ML/DL concepts, and Agentic AI.
  - `ai_tools_and_services.md`: Comparison of providers and tooling (OpenRouter vs LiteLLM).
  - `mcp.md`: Model Context Protocol and related AI integration logic.

- **`public/`**
  Static assets like images and diagrams referenced in the notes.

## 🚀 Getting Started

Feel free to browse through the directories above based on what you want to learn or review. Each markdown file is written to be concise and reference-friendly.
